### Installation

1. Download `scummvm-uwp_<version>_x64.zip`
2. Extract and install the `.appx` (sideloading requires Developer Mode on Windows; Xbox uses Developer Mode + Device Portal)
3. Or deploy from source: `./scripts/deploy-xbox.ps1`
